BuildTheory Publisher: Privacy Policy

Last updated: November 25, 2026

BuildTheory Publisher is a private application used only by the owner of the BuildTheory YouTube channel. It is not offered to the public.

What it accesses

With the channel owner's permission (Google OAuth), it uploads and schedules the owner's own videos, sets their titles, descriptions, captions and visibility, and reads the channel's own YouTube Analytics. It does not access other users' accounts or data.

How data is stored

Access tokens are stored only in the owner's local macOS Keychain. Analytics for the owner's channel are stored locally on the owner's computer and are refreshed or deleted in line with the YouTube API Services policies. No data is sold, shared or used for advertising.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Stored data is then deleted.

This application uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
